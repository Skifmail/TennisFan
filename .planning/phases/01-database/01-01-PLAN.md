# Plan 01-01: Phase 1 — База данных клубного модуля

**Phase:** 1 (База данных)  
**Цель:** Создать приложение `apps.clubs` со всеми моделями по спецификации, расширить `tournaments.Tournament` полями `club_id` и `is_open_interclub`. Миграции применить, обратная совместимость сохранена.

**Источники:** PROJECT.md, ROADMAP.md Phase 1, club_dev_spec.docx §0.

---

## Prerequisites

- Django-проект запускается, миграции `users` и `tournaments` применены.
- Решение из STATE.md: клубный функционал в приложении `apps.clubs`; расширение `Tournament` через миграцию в `apps.tournaments`.

---

## Task 1: Создать приложение apps.clubs

- Создать директорию `apps/clubs/`.
- Файлы: `__init__.py`, `apps.py` (AppConfig с `name = "apps.clubs"`, `verbose_name = "Клубы"`), `models.py` (пока пустой или с заглушкой), `admin.py` (пустой или с `default_app_config`), при необходимости пустые `views.py`, `urls.py`.
- Добавить `"apps.clubs"` в `INSTALLED_APPS` в `config/settings.py` **после** `"apps.tournaments"` (чтобы в миграциях tournaments можно было ссылаться на clubs.Club).

**Проверка:** `python manage.py check` без ошибок.

---

## Task 2: Модели ядра клуба (Club, ClubSubscription, ClubMember)

В `apps/clubs/models.py` объявить:

**2.1. Club**

- Поля: `name` (CharField 255), `slug` (SlugField unique), `city` (CharField 100), `address` (TextField), `logo` (ImageField upload_to="clubs/", blank, с валидатором размера по аналогии с courts — опционально), `email` (EmailField), `phone` (CharField 50, blank), `admin_name` (CharField 255), `description` (TextField blank), `is_public` (BooleanField default True), `status` (CharField choices: active, suspended, trial), `trial_ends_at` (DateTimeField null, blank), `created_at` (DateTimeField auto_now_add=True).
- Meta: verbose_name "Клуб", verbose_name_plural "Клубы", ordering по имени или created_at.
- `__str__`: название клуба.

**2.2. ClubSubscription** (FK → Club)

- Поля: `club` (ForeignKey Club, CASCADE, related_name="subscriptions"), `plan` (CharField choices: start, basic, pro), `period` (CharField choices: monthly, yearly), `price` (DecimalField 10,2), `started_at`, `ends_at` (DateTimeField), `auto_renew` (BooleanField default False), `payment_provider` (CharField 50, blank), `payment_ref` (CharField 255, blank), `status` (CharField choices: active, expired, cancelled).
- Meta: ordering по ends_at или id.
- `__str__`: клуб + план + период.

**2.3. ClubMember** (FK → Club, FK → User)

- Поля: `club` (ForeignKey Club, CASCADE, related_name="members"), `user` (ForeignKey settings.AUTH_USER_MODEL, CASCADE, related_name="club_memberships"), `role` (CharField choices: admin, manager, player), `status` (CharField choices: active, invited, removed), `invited_by` (ForeignKey User, null, blank, related_name="invited_club_members"), `joined_at` (DateTimeField null, blank), `created_at` (DateTimeField auto_now_add=True).
- Meta: unique_together (club, user); verbose_name "Участник клуба".
- `__str__`: user.email + клуб.

**Проверка:** `python manage.py makemigrations clubs` — создаётся первая миграция (например 0001_initial). Не применять пока, если хотим одной миграцией с инвайтами.

## Task 3: Модель ClubInviteLink

В `apps/clubs/models.py` добавить:

**ClubInviteLink**

- Поля: `club` (ForeignKey Club, CASCADE, related_name="invite_links"), `token` (CharField 64, unique), `created_by` (ForeignKey User, CASCADE), `expires_at` (DateTimeField null, blank), `max_uses` (PositiveIntegerField null, blank), `use_count` (PositiveIntegerField default 0), `is_active` (BooleanField default True), `created_at` (DateTimeField auto_now_add=True).
- Meta: verbose_name "Инвайт-ссылка".
- Утилита генерации токена: `secrets.token_urlsafe(32)` или аналог (64 символа).

Включить ClubInviteLink в ту же миграцию 0001 (если ещё не применена) или сделать 0002. Затем выполнить миграции клубов: `python manage.py migrate clubs`.

**Проверка:** `python manage.py migrate clubs` успешно.

## Task 4: Расширение модели Tournament

В `apps/tournaments/models.py` в класс `Tournament` добавить поля (после существующих FK, например после `court`):

- `club` — ForeignKey("clubs.Club", on_delete=SET_NULL, null=True, blank=True, related_name="tournaments", verbose_name="Клуб").
- `is_open_interclub` — BooleanField("Открытый межклубный", default=False).

Выполнить: `python manage.py makemigrations tournaments` — имя миграции вроде `add_club_fields` или по умолчанию. Затем `python manage.py migrate`.

**Проверка:** В БД у таблицы турниров есть колонки club_id и is_open_interclub; существующие турниры имеют club_id=NULL.

## Task 5: Модели взносов (ClubMembershipFee, ClubFeePayment)

В `apps/clubs/models.py` добавить:

**5.1. ClubMembershipFee** (FK → Club)

- Поля: `club` (ForeignKey Club, CASCADE, related_name="membership_fees"), `amount` (DecimalField 10,2), `currency` (CharField 3, default="RUB"), `period` (CharField choices: monthly, quarterly, yearly), `period_start_day` (PositiveSmallIntegerField default 1, 1–28), `description` (TextField blank), `restrict_tournament_access` (BooleanField default False), `payment_provider` (CharField choices: yookassa, stripe или 50), `payment_api_key` (TextField blank — позже шифрование), `payment_shop_id` (CharField 255, blank), `is_active` (BooleanField default False), `created_at` (DateTimeField auto_now_add=True).
- Meta: verbose_name "Настройка взносов клуба".

**5.2. ClubFeePayment** (FK → Club, ClubMember, ClubMembershipFee; опционально FK → User для marked_by)

- Поля: `club` (ForeignKey Club, CASCADE), `member` (ForeignKey ClubMember, CASCADE), `fee` (ForeignKey ClubMembershipFee, CASCADE), `amount` (DecimalField 10,2), `period_label` (CharField 50, напр. "2026-03"), `paid_at` (DateTimeField), `method` (CharField choices: online, manual), `payment_ref` (CharField 255, blank), `marked_by` (ForeignKey User, null, blank).
- Meta: verbose_name "Оплата взноса".

Создать миграцию: `python manage.py makemigrations clubs`, применить: `python manage.py migrate clubs`.

## Task 6: Модели рейтинга (ClubRating, ClubRatingHistory)

В `apps/clubs/models.py` добавить:

**6.1. ClubRating** (FK → Club, ClubMember)

- Поля: `club` (ForeignKey Club, CASCADE, related_name="ratings"), `member` (OneToOneField ClubMember, CASCADE, related_name="club_rating" — один рейтинг на участника в клубе), `points` (IntegerField default 0), `rank` (PositiveIntegerField null, blank), `updated_at` (DateTimeField auto_now=True).
- Meta: verbose_name "Рейтинг в клубе", unique по (club, member) через OneToOne на member.

**6.2. ClubRatingHistory** (FK → ClubRating, Tournament)

- Поля: `club_rating` (ForeignKey ClubRating, CASCADE, related_name="history"), `tournament` (ForeignKey "tournaments.Tournament", SET_NULL, null, blank), `points_before` (IntegerField), `points_after` (IntegerField), `delta` (IntegerField), `created_at` (DateTimeField auto_now_add=True).
- Meta: verbose_name "История рейтинга".

Добавить в ту же или следующую миграцию клубов, применить.
