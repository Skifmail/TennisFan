# Страница «Видео» - Руководство по использованию

## Описание

Страница «Видео» позволяет управлять прямыми трансляциями и плейлистом видео через админ-панель Django. Поддерживаются платформы: YouTube, VK, RuTube.

## Установка

1. **Создайте миграции:**
   ```bash
   python manage.py makemigrations content
   python manage.py migrate
   ```

2. **Добавьте страницу в навигацию:**
   - Перейдите в админ-панель → Навигация → Пункты меню
   - Добавьте новый пункт:
     - Название: "Видео"
     - URL: `/videos/`
     - Порядок: установите нужный порядок
     - Активен: ✓

## Использование

### Управление через админ-панель

1. **Настройка страницы:**
   - Перейдите в админ-панель → Контент → Страница «Видео»
   - Отредактируйте заголовки блоков:
     - "Заголовок блока «Прямые трансляции»"
     - "Заголовок блока «Плейлист»"

2. **Добавление прямой трансляции:**
   - В том же разделе админки найдите блок "Прямые трансляции"
   - Нажмите "+ Добавить еще одну Прямая трансляция"
   - Заполните:
     - **Название трансляции**: например, "Финальный матч турнира"
     - **Ссылка на трансляцию**: вставьте ссылку на трансляцию
     - **Платформа**: выберите автоматически определится по ссылке
     - **Активна**: ✓ (чтобы показывать на сайте)
     - **Порядок**: для сортировки

3. **Добавление видео в плейлист:**
   - В блоке "Видео" нажмите "+ Добавить еще одно Видео"
   - Заполните:
     - **Название видео**: например, "Обзор турнира"
     - **Описание**: краткое описание (опционально)
     - **Ссылка на видео**: вставьте ссылку на видео
     - **Платформа**: автоматически определится
     - **URL превью**: опционально (если не указано, используется превью с платформы)
     - **Опубликовано**: ✓
     - **Порядок**: для сортировки

### Форматы ссылок

#### YouTube
- Обычное видео: `https://www.youtube.com/watch?v=VIDEO_ID`
- Короткая ссылка: `https://youtu.be/VIDEO_ID`
- Прямая трансляция: `https://www.youtube.com/watch?v=STREAM_ID`

#### VK
- Видео: `https://vk.com/video-123456_789`
- Или: `https://vk.com/video123456_789`
- Прямая трансляция: `https://vk.com/video-123456_789` (если это трансляция)

#### RuTube
- Видео: `https://rutube.ru/video/VIDEO_ID/`
- Прямая трансляция: `https://rutube.ru/video/STREAM_ID/`

## Возможности

### Просмотр на сайте
- Все видео встраиваются прямо на страницу через iframe
- Пользователи могут смотреть видео без перехода на другую платформу
- Поддерживается полноэкранный режим

### Переход в приложение
- Под каждым видео есть ссылка "Открыть в [Платформа] →"
- При клике открывается оригинальное видео на платформе в новой вкладке

### Адаптивность
- Страница адаптирована под мобильные устройства
- Видео автоматически подстраиваются под размер экрана
- Сохраняется соотношение сторон 16:9

## Структура страницы

1. **Блок "Прямые трансляции"**
   - Показываются только активные трансляции (`is_active=True`)
   - Сортировка по полю `order`, затем по дате создания

2. **Блок "Плейлист"**
   - Показываются только опубликованные видео (`is_published=True`)
   - Сортировка по полю `order`, затем по дате создания
   - Отображается количество просмотров (если > 0)

## Технические детали

### Модели
- `VideoPage` - настройки страницы (singleton)
- `LiveStream` - прямые трансляции
- `Video` - видео в плейлисте

### URL
- Страница доступна по адресу: `/videos/`
- Имя URL: `videos`

### Шаблон
- Файл: `templates/content/videos.html`
- Использует базовый шаблон `base.html`

## Примеры использования

### Пример 1: Добавление YouTube трансляции
1. Скопируйте ссылку на трансляцию: `https://www.youtube.com/watch?v=dQw4w9WgXcQ`
2. В админке добавьте трансляцию с этой ссылкой
3. Платформа определится автоматически как "YouTube"
4. Трансляция появится на странице `/videos/`

### Пример 2: Добавление VK видео
1. Скопируйте ссылку: `https://vk.com/video-123456_789`
2. Добавьте в плейлист через админку
3. Видео будет встроено на страницу

### Пример 3: Изменение заголовков
1. В админке откройте "Страница «Видео»"
2. Измените "Заголовок блока «Прямые трансляции»" на "Онлайн-трансляции"
3. Сохраните
4. На странице заголовок обновится автоматически

## Примечания

- Для VK видео может потребоваться дополнительная настройка прав доступа на самой платформе
- Прямые трансляции показываются только когда они активны
- Видео в плейлисте можно скрыть, сняв галочку "Опубликовано"
- Порядок отображения можно менять через поле "Порядок" в админке
