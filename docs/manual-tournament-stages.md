# Ручной отбор и две олимпийские сетки

Сценарий доступен внутри обычных форматов «Круговой» и «Олимпийский (до 1 поражения)». Поле формата не меняется, раздел «Группы + плей-офф» не используется.

1. В управлении турниром выбрать «Вручную», запустить турнир.
2. До сохранения обычных пар нажать «Круговой отбор → две сетки».
3. Распределить всех игроков или полные команды по 1–8 отборочным пулам. Для сценария нужно минимум 4 участника, в каждом пуле — минимум 2. Сохранение создаёт полное круговое расписание внутри каждого пула.
4. Внести результаты всех матчей. Таблицы отбора пересчитываются штатным круговым алгоритмом. До фиксации двух сеток результат отбора можно исправить.
5. Выбрать для каждого участника основную или утешительную сетку и порядок посева. Организатор определяет проходные места самостоятельно: доступны в том числе четвёртые места. Все действующие участники должны попасть ровно в одну сетку; минимум двое в каждой.
6. Сохранить обе сетки одновременно. Пары образуются из соседних позиций по порядку посева; первые позиции получают свободный проход при неполной сетке. Посев и отбор после этого зафиксированы. Победители проходят по созданному дереву автоматически. В каждой ветви первое поражение прекращает участие.
7. Внести результаты обеих сеток. Турнир завершается после обоих финалов; основная сетка не закрывает утешительную. Места утешительной сетки следуют за местами основной. Проигравшие в одном круге делят место (например, оба полуфиналиста занимают третье место). Сезонные очки за место начисляются один раз в конце. Само свободное прохождение не считается сыгранным матчем.

Публичная карточка, PDF сетки и регламент отражают отдельные этапы. Права управления остаются штатными: staff для турнира платформы, администратор/менеджер соответствующего клуба для клубного турнира.

Обычный ручной сценарий без отбора и автоматические турниры продолжают работать как раньше. Переключить начатые обычные матчи на новый сценарий нельзя. Состав отборов и посев после сохранения не перестраиваются: это исключает потерю результатов и повторное начисление очков. Для взаимной неявки без победителя организатору потребуется определить дальнейшее решение матча до продолжения ветви.
