# Публичный каталог тренировок

Редизайн `/training/`, 23 ноября 2026 года.

## Границы изменений

- Шаблоны каталога и его карточки; отдельный `static/css/pages/training_catalog.css`.
- Только цветовые переменные и шрифты платформы. Новые акценты и внешние шрифты не добавлены.
- Страницы тренировки, запись, кабинет и административное распределение заявок не изменены. Миграций нет.
- Общий CSS-бандл не редактируется; локальный CSS подключается через `extra_css` и попадает в стандартный static manifest.

## Поведение

- В карточке сохранены название, города, тренер, описание, все форматы и уровни, цена и отдельная аренда корта; добавлена длительность.
- Фотографии показываются целиком (`object-fit: contain`). Карточка — `article` с одной растянутой ссылкой и видимым клавиатурным фокусом.
- Фильтры применяются GET-кнопкой или Enter, не перезагружая страницу при выборе поля. Есть количество результатов, сброс и действия для пустой выдачи.
- Район Москвы открывается ссылкой. С JavaScript ссылка сохраняет ещё не применённые спорт, формат и уровень; без JavaScript сохраняет фильтры текущей страницы. Выбор района явно задаёт Москву.
- Корты выбранной территории раскрываются нативным `details`; поиск по названию сохранён. Без JavaScript доступны весь список и обычные ссылки.
- При смене города район очищается перед отправкой. Без JavaScript сервер также игнорирует московский район для другого явно заданного города.
- Сортировка по близости и географическая модель остаются прежними.

## Адаптивность и доступность

- Карточки: три колонки от 1200 px, две от 700 px, одна ниже.
- Поля: четыре колонки от 900 px, две ниже, одна ниже 380 px.
- Цели управления не меньше 44 px; поля не меньше 46 px и шрифт не меньше 16 px, даже при мобильном уменьшении корневого шрифта платформы.
- Названия полей заданы явно через `aria-labelledby`; длинный текст переносится без обрезки.
- Короткая обратная связь на нажатие, без общей анимации появления карточек; `prefers-reduced-motion` отключает движение.

## Проверка

Новые проверки находятся в `tests/integration/test_training_catalog.py` и `tests/e2e/test_training_catalog_browser.py`; фикстура — `tests/support/training_catalog.py`.

Браузерная приёмка охватывает 13 ширин от 320 до 1440 px, обычный и reduced motion, несколько фильтров, Enter, сброс, пустую выдачу, сохранение черновых фильтров при выборе района, корты, фокус и клик по фотографии. Реальные фотографии дополнительно просмотрены при 390, 768 и 1440 px.

Новые браузерные тесты, scoped mypy strict, Black, Ruff, Stylelint и синтаксис JavaScript добавлены в существующий workflow `deployment-checks.yml`.

Приёмка каталога и прежней географии на отдельном PostgreSQL: **61 passed**, 20 успешных subtests, включая 32 браузерные проверки. Scoped mypy strict трёх новых Python-файлов, Black, Ruff, Stylelint, JS syntax и `git diff --check` проходят.

Расширенный локальный PostgreSQL-прогон раздела: 200 passed, 59 успешных subtests; один прежний тест `test_contacts_stay_available_when_telegram_or_copying_is_blocked[long]` не проходит при сохранении email длиннее модельного VARCHAR(200), до взаимодействия с интерфейсом. Этот тест и модель не менялись; увеличивать лимиты или ослаблять проверки ради редизайна не стали.
