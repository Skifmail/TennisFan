Алгоритм расчета рейтинга FAN

Математическая модель и алгоритм пересчета рейтинга силы игрока

Эта страница описывает математические основы системы расчета рейтинга FAN (FAN-очки), используемой в TennisFan для определения уровня силы игроков.

1. Начальный рейтинг

1.1. При регистрации каждый игрок проходит тест NTRP (National Tennis Rating Program) для определения начального уровня силы от 1.0 до 7.0.

1.2. На основе результата теста игроку присваивается начальный рейтинг FAN (FAN-очки) в диапазоне от 1000 до 7000 очков согласно следующей таблице:

NTRP уровень FAN очки
1.0 – 1.4 1000
1.5 – 1.8 1500
1.9 – 2.0 2000
2.1 – 2.5 2500
2.6 – 3.0 3000
3.1 – 3.5 3500
3.6 – 4.0 4000
4.1 – 4.5 4500
4.6 – 5.0 5000
5.1 – 5.5 5500
5.6 – 6.0 6000
6.1 – 6.5 6500
6.6 – 7.0 7000

1.3. Для уровней внутри диапазона (например, 2.8 или 3.0) рейтинг интерполируется линейно между границами диапазона для обеспечения точного соответствия между NTRP уровнем и FAN очками.

2. Основной алгоритм расчета рейтинга после матча

После каждого завершенного матча рейтинг обоих игроков пересчитывается по формуле:

Rновый = Rстарый + K × (Sреальное - Sожидаемое)

где:

  • Rновый — новый рейтинг игрока после матча
  • Rстарый — текущий рейтинг игрока до матча
  • K — коэффициент динамичности (K-фактор)
  • Sреальное — реальный результат игрока в матче
  • Sожидаемое — ожидаемый результат, рассчитанный системой до матча

3. Ожидаемый результат (Sожидаемое)

3.1. Перед матчем система рассчитывает вероятность победы каждого игрока на основе разницы в их рейтингах по формуле:

EA = 1 / (1 + 10((RB - RA) / 800))

где:

  • EA — ожидаемый результат игрока A (вероятность победы или доля очков)
  • RA — рейтинг игрока A
  • RB — рейтинг игрока B
  • 800 — делитель, определяющий чувствительность системы к разнице в рейтингах

3.2. Делитель 800 означает, что разница в 800 очков дает сильнейшему игроку примерно 90% вероятность победы. Это настроено для любительского тенниса, где результаты более непредсказуемы, чем в профессиональном.

3.3. Примеры:

  • Если рейтинги равны (RA = RB): EA = 0.5 (50% вероятность)
  • Если разница 200 очков: EA ≈ 0.75 (75% вероятность для сильнейшего)
  • Если разница 400 очков: EA ≈ 0.88 (88% вероятность для сильнейшего)

4. Реальный результат (Sреальное)

4.1. Реальный результат рассчитывается на основе счета матча и учитывает два фактора:

Sреальное = 0.7 × (геймы выиграно / всего геймов) + 0.3 × бонус за победу

где:

  • 0.7 — вес доли выигранных геймов (70%)
  • 0.3 — вес бонуса за победу в матче (30%)
  • бонус за победу = 1.0, если игрок выиграл матч, и 0.0, если проиграл

4.2. Примеры расчета:

  • Победа 6:2, 6:2: S = 0.7 × (12/16) + 0.3 × 1.0 = 0.7 × 0.75 + 0.3 = 0.825
  • Победа 7:6, 7:6: S = 0.7 × (14/26) + 0.3 × 1.0 = 0.7 × 0.538 + 0.3 = 0.677
  • Поражение 4:6, 2:6: S = 0.7 × (6/18) + 0.3 × 0.0 = 0.7 × 0.333 + 0.0 = 0.233

4.3. Система учитывает не только факт победы/поражения, но и счет по геймам, что делает расчет более справедливым. Уверенная победа дает больше очков, чем победа в упорной борьбе.

5. Коэффициент динамичности (K-фактор)

5.1. K-фактор определяет, насколько сильно изменяется рейтинг после каждого матча. Он зависит от количества сыгранных матчей:

Количество матчей K-фактор Описание
Меньше 10 250 Фаза калибровки — рейтинг быстро корректируется
10 и больше 50 Стабилизированный рейтинг — изменения плавные

5.2. Логика K-фактора:

  • Для новичков (менее 10 матчей): K = 250 позволяет системе быстро корректировать "ошибки" начальной оценки. Один матч может изменить рейтинг на 50-100 очков, что помогает игроку быстро достичь своего реального уровня.
  • Для опытных игроков (10+ матчей): K = 50 обеспечивает стабильность рейтинга. Изменения становятся плавными и отражают реальный прогресс, а не случайности одного матча.

6. Примеры расчета

Пример 1: Новичок против опытного игрока

Условия:

  • Игрок A (новичок): рейтинг 3000, сыграно 3 матча (K = 250)
  • Игрок B (опытный): рейтинг 4000, сыграно 25 матчей (K = 50)
  • Результат: Игрок A выиграл 6:4, 6:4

Расчет:

  • Ожидаемый результат A: EA = 1 / (1 + 10((4000-3000)/800)) = 1 / (1 + 101.25) ≈ 0.06 (6%)
  • Реальный результат A: SA = 0.7 × (12/20) + 0.3 × 1.0 = 0.7 × 0.6 + 0.3 = 0.72
  • Изменение рейтинга A: ΔRA = 250 × (0.72 - 0.06) = 250 × 0.66 = +165 очков
  • Новый рейтинг A: 3000 + 165 = 3165 очков

Для игрока B:

  • Ожидаемый результат B: EB = 1 - EA = 0.94 (94%)
  • Реальный результат B: SB = 0.7 × (8/20) + 0.3 × 0.0 = 0.28
  • Изменение рейтинга B: ΔRB = 50 × (0.28 - 0.94) = 50 × (-0.66) = -33 очка
  • Новый рейтинг B: 4000 - 33 = 3967 очков

Вывод: Новичок получил значительно больше очков (+165), так как его победа была неожиданной. Опытный игрок потерял меньше очков (-33), так как его рейтинг уже стабилизирован.

Пример 2: Равные игроки

Условия:

  • Игрок A: рейтинг 3500, сыграно 15 матчей (K = 50)
  • Игрок B: рейтинг 3500, сыграно 20 матчей (K = 50)
  • Результат: Игрок A выиграл 7:6, 5:7, 7:6

Расчет:

  • Ожидаемый результат A: EA = 1 / (1 + 100) = 0.5 (50%)
  • Реальный результат A: SA = 0.7 × (19/38) + 0.3 × 1.0 = 0.7 × 0.5 + 0.3 = 0.65
  • Изменение рейтинга A: ΔRA = 50 × (0.65 - 0.5) = 50 × 0.15 = +7.5 очков
  • Новый рейтинг A: 3500 + 7.5 = 3507.5 очков

Для игрока B:

  • Реальный результат B: SB = 0.7 × (19/38) + 0.3 × 0.0 = 0.35
  • Изменение рейтинга B: ΔRB = 50 × (0.35 - 0.5) = 50 × (-0.15) = -7.5 очков
  • Новый рейтинг B: 3500 - 7.5 = 3492.5 очков

Вывод: При равных рейтингах изменения минимальны, так как результат был ожидаемым. Победитель получил небольшой бонус за победу в упорной борьбе.

7. Пересчет NTRP уровня

7.1. После каждого матча система автоматически пересчитывает NTRP уровень игрока на основе его текущего FAN рейтинга.

7.2. Пересчет происходит по обратной формуле к таблице начальных очков с линейной интерполяцией между диапазонами.

7.3. Примеры соответствия:

  • 3000 очков → NTRP 2.6
  • 3222 очков → NTRP 3.0
  • 3500 очков → NTRP 3.1
  • 4000 очков → NTRP 3.6
  • 5000 очков → NTRP 4.6

8. Особенности системы

8.1. Самокоррекция

Если игрок завысил свой уровень при регистрации (например, получил NTRP 5.0, а играет на уровне 3.0), система быстро скорректирует рейтинг. При большом K-факторе (250) игрок будет терять по 100-200 очков за матч, и через 3-4 игры его рейтинг упадет до реального уровня.

8.2. Справедливость счета

Проигрыш 0:6 наказывает сильнее, чем проигрыш 6:7. Система учитывает не только факт победы/поражения, но и счет по геймам, что делает оценку более точной.

8.3. Защита опытных игроков

Игрок, сыгравший 50+ матчей, имеет стабильный рейтинг (K = 50). Один плохой день не обрушит его статистику, в отличие от новичка с K = 250.

8.4. Нулевая сумма изменений

В матче между двумя игроками с одинаковым K-фактором сумма изменений рейтингов равна нулю: сколько очков получил один игрок, столько же потерял другой. Это обеспечивает баланс системы.

9. Обновление рейтинга

9.1. Рейтинг обновляется сразу после завершения каждого матча, что позволяет игрокам видеть свой текущий прогресс в реальном времени.

9.2. Рейтинг является постоянным показателем уровня игрока и не сбрасывается между сезонами. Это ваш "паспорт" как теннисиста — если вы достигли уровня 4.0, вы остаётесь на этом уровне и в новом сезоне.

9.3. Рейтинг используется для определения уровня силы (категории: Новичок, Любитель, Опытный, Мастерс, Профессионал), который пересчитывается ежемесячно, 1-го числа каждого месяца.
