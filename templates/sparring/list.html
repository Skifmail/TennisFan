{% if sparring_type == 'singles' %}

Одиночный спарринг 1×1: вы публикуете заявку, другие игроки откликаются, а вы выбираете соперника и по подтверждённому отклику создаётся один матч 1×1 (при желании — дружеский, без влияния на рейтинг).

{% elif sparring_type == 'doubles' %}

Парный спарринг 2×2: автор создаёт заявку и свою команду (можно добавить партнёра), остальные игроки откликаются в команду автора или соперников, автор одобряет отклики и при двух полных командах подтверждает один парный матч 2×2.

{% elif sparring_type == 'team' %}

Командный спарринг: формируются две команды по 2 человека. После того как автор одобрит отклики и наберётся 4 участника, бот и ЛК предложат сформировать серию матчей — каждый играет с каждым из противоположной команды 1×1, а затем создаётся один парный матч между командами.
