Кому поручить жеребьёвку и какую кнопку нажать?
  1. Для одной обычной сетки выберите «Автоматически» и нажмите «Запустить турнир». Платформа сформирует матчи по выбранному формату.
  2. Если хотите решать по ходу дня, выберите «Вручную» → «Запустить турнир» → «Добавить этап». На странице управления уже созданными сетками эта кнопка называется «Открыть ручные этапы».
  3. Если хотите лично составлять каждую пару по кругам, выберите «Составить пары». Укажите соперников, нажмите «Проверить и сохранить круг», проверьте пары и подтвердите «Сохранить круг».

Выберите между отдельными парами и этапами до сохранения первых матчей. После сохранения круга перейти к конструктору этапов в этом турнире уже нельзя.

Какую схему выбрать на корте

Тур объединяет сетки. Например, «Отборочный тур» — это тур, а «Группа А» и «Группа Б» — две сетки внутри него. Число игроков в примерах можно менять.

Пришло 6 игроков. Хочу начать сразу с финала
  1. Откройте «Добавить этап». В поле «Тур» выберите «Финальный тур», в поле «Название сетки» напишите «Общий финал».
  2. Выберите «Круговой», если все должны сыграть друг с другом. Для шести человек это 15 матчей. Если времени мало, «Олимпийский на выбывание» определит победителя за 5 сыгранных матчей.
  3. Отметьте шестерых и нажмите «Создать сетку и матчи». После последнего результата перейдите к общему зачёту и укажите для финала место 1.
Пришло 18 игроков. Уровень известен, отбор можно пропустить
  1. Выберите «Основной тур». Создайте сетку «Сильная», отметьте её участников и сохраните. Затем выберите тот же тур и создайте сетку «Вторая» для остальных.
  2. Для каждой сетки выберите свой формат. В круговой каждый встречается с каждым. В олимпийской на выбывание поражение заканчивает выступление в этой сетке. В формате «Олимпийский за все места» проигравшие продолжают розыгрыш мест.
  3. Если общий финал не нужен, после матчей задайте диапазоны мест обеих сеток. Например, при девяти игроках в каждой первая сетка начинается с места 1, вторая — с места 10.
Пришло 60 игроков. Сначала хочу провести отбор по группам
  1. Выберите «Отборочный тур». Создайте круговую «Группу А», отметив только её игроков. Повторите для остальных групп с тем же названием тура. Например, 60 игроков можно распределить в 15 групп по четыре. Каждая такая группа сыграет шесть матчей.
  2. Заносите результаты. Посмотрите места в таблицах групп. Когда группа закончила все матчи, её игроков можно выбрать для следующего тура.
  3. В «Основном туре» создайте новые сетки. Например, вручную отметьте первых и вторых из каждой группы для сильной сетки, остальных — для второй. Обе могут быть круговыми или олимпийскими. Для олимпийской проверьте номера посева перед сохранением. Если участников меньше, чем ячеек сетки, первые номера посева пройдут первый круг без игры.
Осталось время. Хочу свести финалистов разных сеток
  1. Дождитесь результатов обеих сеток. Откройте ручные этапы и выберите «Финальный тур». Для общего кругового финала создайте одну сетку и отметьте нужных игроков из обеих таблиц.
  2. Для отдельных матчей за медали создайте в этом же туре две сетки по два игрока. Назовите первую «Финал», вторую «Матч за бронзу». В каждой отметьте нужную пару и сохраните.
  3. Можно добавить и четвёртый тур. В поле «Тур» введите новое название и выберите участников. Завершайте турнир, когда все запланированные игры сыграны.
Всегда играем круговой отбор и две олимпийские сетки
  1. До создания первых матчей откройте «Добавить этап» и раскройте готовую схему «Круговой отбор и две олимпийские сетки».
  2. Распределите всех по отборам, минимум по двое. Нажмите «Сохранить отборы и создать матчи». После окончания всех отборов распределите игроков в основную и утешительную сетки, задайте посев и нажмите «Создать обе олимпийские сетки».
  3. После двух финалов турнир завершится автоматически. Если хотите оставить возможность сыграть ещё один тур, с самого начала используйте свободный сценарий «Добавить этап».

Результаты и места

Куда вносить счёт сыгранного матча?
  1. {% if supports_manual_pairing %}Для турнира с ручными этапами откройте «Открыть ручные этапы» и найдите встречу под названием её сетки. При ведении отдельных пар используйте «Пары и результаты».{% else %}Найдите встречу в списке матчей своей группы или сетки.{% endif %}
  2. Сверьте имена над полями счёта. Введите геймы каждого сыгранного сета, отметьте победителя и нажмите «Сохранить».
  3. Проверьте сохранённый счёт до запуска следующей сетки. {% if supports_manual_pairing %}Если при создании нового этапа игрок недоступен, рядом с именем указана его текущая сетка. Завершите все её матчи.{% endif %}
{% if supports_manual_pairing %}
Как собрать один пьедестал из финала и матча за бронзу?
  1. После всех матчей откройте «Подвести итоги» на странице ручных этапов. У каждой сетки есть поле «С места».
  2. У «Финала» введите 1: его игроки займут первое и второе места. У «Матча за бронзу» введите 3: победитель получит бронзу, второй игрок займёт четвёртое место.
  3. Чтобы учесть остальных, укажите у следующей сетки 5. Игрок, уже получивший место выше, повторно в зачёт не попадёт. Для ещё одной сетки укажите следующее свободное место. Поля сеток, которые не участвуют в зачёте, оставьте пустыми.
  4. Нажмите «Проверить общий зачёт». Сверьте места и список участников без места. Чтобы изменить распределение, поправьте числа и повторите проверку.
  5. Когда таблица верна, нажмите «Опубликовать этот зачёт и завершить турнир». Именно тогда будут начислены сезонные очки. После публикации добавить ещё один тур нельзя.
{% endif %}
Где игроки увидят результаты и как распечатать сетку?
  1. Вверху панели нажмите «Открыть публичную страницу». Там можно проверить, какие матчи и результаты уже видны участникам.
  2. Для печати нажмите «Скачать сетку (PDF)». Рядом доступен регламент турнира в PDF и Word.
